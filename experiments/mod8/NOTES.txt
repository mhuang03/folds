a(N) MODULO 8 AND 16                                              (experiments/mod8/)
==========================================================================================
Notation as in experiments/arith/FINDINGS.txt: a(N) = #semi-symmetric (valid) sequences,
R = reversal, M = mirror (m -> N+1-m), c(N) = #Fix(RM) (self-dual), sigma(m) = N+1-m,
W(m) = window of m.  g(S) = number of valid orderings of the set S as the first |S| steps.
Complement lemma: the number of valid completions of a prefix with set A is g([N] \ A).
Two adjacent steps x, y are *independent* if x is not in W(y) and y is not in W(x); an
adjacent pair of a valid sequence can be exchanged (result again valid) iff it is
independent.  All runs <= 2 cores, < 6 GB.

SHORT ANSWER
  * a(N) mod 8 is NOT a function of the self-dual data: (c mod 16, d mod 8) does not
    determine a mod 8 (collisions in the table below), and generic V4-orbits (size 4)
    contribute 4 each, so a mod 8 needs the parity of the number of free V4-orbits,
    (a - c)/4 mod 2, which looks random (table).  No prediction of a(39..41) mod 8 was
    possible; a(N) mod 4 = c(N) mod 4 stays the best known (FINDINGS.txt).
  * Exact congruences found (sections 1-3), all verified numerically, (2) also in Lean:
      (1) a(2n)   == #{S : |S| = n, g(S) and g(S^c) odd}                 (mod 8)
          a(2n+1) == #{(S, m) : |S| = n, m valid after S, g(S), g(T) odd} (mod 8),
          T = [N] \ S \ {m}; more generally mod 2^k with g reduced mod 2^(k-2).
      (2) [Lean, Folds/Congruence2.lean]  N = 2n >= 4:
          #{valid seqs with independent middle pair (steps n, n+1)}
             == #{self-dual seqs with independent middle pair}          (mod 8)
          (= #{self-dual seqs whose last half step is an outer pair}, = c - d), and both
          are == 0 (mod 4).  Equivalently a(2n) + d == c + r (mod 8), r = #{valid seqs
          whose middle pair is dependent}, d = #{self-dual seqs, inner last half step}.
      (3) for a reversal-symmetric pair of adjacent position pairs (i, i+1), (N-2-i, N-1-i)
          (disjoint, not the middle):  #{valid seqs where at least one of the two pairs is
          independent} == 2 #{self-dual seqs with pair i independent} (mod 8).
      (4) "rigid" form: a(N) == #Z + #T1 (mod 8), Z = sequences in which every pair of a
          reversal-invariant family P of disjoint adjacent position pairs is dependent.

------------------------------------------------------------------------------------------
0. GENERAL PRINCIPLE                                                             [proof]
------------------------------------------------------------------------------------------
For a finite 2-group G acting on X: |X| == #{x : |G x| < 2^k}  (mod 2^k), since orbits of
size >= 2^k are multiples of 2^k.  With G = V4 = <R, M> (R, M free) this is a == c mod 4.
To go further one needs a bigger 2-group acting on the valid sequences.  The only global
symmetries are V4 (FINDINGS.txt); every further involution found is LOCAL (exchanging
independent adjacent steps, or a whole meet-in-the-middle split), and its fixed set is a
positive fraction of everything, so the residual sets are not small.

------------------------------------------------------------------------------------------
1. MEET-IN-THE-MIDDLE PARITY FORMULA                     [proof; verified N = 2..24]
------------------------------------------------------------------------------------------
Even N = 2n:  a = sum_{|S|=n} g(S) g(S^c).  V4 acts on n-sets by S -> S^c (from R, via
the complement lemma) and S -> sigma(S) (from M); the summand is constant on orbits
(g(sigma S) = g(S)).  Orbits:
  - free {S, S^c, sigma S, sigma S^c}: contributes 4 g(S) g(S^c);
  - S = sigma S (symmetric; then S^c too): M acts freely on orderings of S (no middle
    panel), so g(S), g(S^c) are even and the orbit {S, S^c} contributes 2 g g' == 0 mod 8;
  - S^c = sigma S (transversal T): contributes 2 g(T)^2.
S = S^c is impossible.  Mod 8: a free orbit gives 4 iff g(S)g(S^c) is odd (and then all
4 sets have odd product), a transversal orbit gives 2 iff g(T) is odd (odd squares == 1).
Hence
      a(2n) == #{S : |S| = n, g(S) odd and g(S^c) odd}   (mod 8).
Odd N = 2n+1: a = sum over (S, m, T) (S, {m}, T partition [N], |S| = |T| = n) of
g(S) [m valid after S] g(T); m valid after S iff valid after T (window split).  V4 acts by
(S,m,T) -> (T,m,S), (sigma S, sigma m, sigma T).  Swap-fixed points do not exist; sigma-fixed
ones have S, T symmetric (g even, contribution 2 g g' == 0 mod 8); the RM-type fixed points
T = sigma S, m = middle contribute 2 g(S)^2.  Same conclusion:
      a(2n+1) == #{(S, m) : |S| = n, m valid after S, g(S), g(T) both odd}  (mod 8).
Mod 2^k (k >= 3): the same argument gives a == sum gbar(S) gbar(S^c) (mod 2^k) with
gbar = g mod 2^(k-2) (and likewise for odd N); checked mod 16 with g mod 4, N = 2..22.
Files: parity.c (g mod 2 as a bit array, out: parity_out.txt, N = 2..24, also the number of
odd-g sets by size), parity4.c (g mod 4; parity4_out.txt).
Note: the odd-g sets are not sparse (about 39% of the 11-sets of [22]), and computing g
mod 2 still needs the full 2^N subset DP, so this does not extend a mod 8 past N = 38.

------------------------------------------------------------------------------------------
2. THE MIDDLE SWAP: A THIRD INVOLUTION FOR EVEN N           [Lean; verified N <= 26]
------------------------------------------------------------------------------------------
N = 2n.  T = exchange steps n and n+1 (positions n-1, n, 0-based) if that gives a valid
sequence (iff the two middle panels are independent).  T commutes with R (reversal maps
the middle pair to itself) and with M.  On Y = {x : T x != x} = midSwappable:
  - T, M, R free; TM free (the first entry would be sigma of itself, N even);
    TR free (first entry = last entry); TRM free (entry n-1 would be sigma of itself).
  - so every stabiliser in <R, M, T> = (Z/2)^3 is {1} or {1, RM}: orbits of size 8, or of
    size 4 consisting of self-dual sequences.
Hence  #Y == #(Y cap Fix RM) (mod 8).  On Y cap Fix RM, <M, T> acts freely (TM free), so it is
== 0 mod 4.  For self-dual sequences the middle pair is (m, sigma m) and T is exactly the
flip of the last half step (Folds/SelfDual.lean): independent <=> outer pair (3m <= N+1).
So #Y(2n) == c(2n) - d(2n) (mod 8), d = inner count (FINDINGS.txt flip lemma).
Lean (Folds/Congruence2.lean):
  card_mod_eight_free   (Z/2)^3 acting freely => 8 | |X|  (via the pairs {x, Tx} and
                        card_mod_four on them)
  card_mod_eight        |X| == |Fix RM| (mod 8) if all elements except 1, RM are free
  midSwappable_mod_eight, midSwappable_selfDual_mod_four, midSwappable_mod_four,
  semiCount_mod_eight_mid  (a(2n) + d == c + r  mod 8)

------------------------------------------------------------------------------------------
3. OTHER SYMMETRIC SWAPS AND THE RIGID FORMULA            [proof; verified N = 4..16]
------------------------------------------------------------------------------------------
For a position pair i (exchange of steps i+1, i+2) with reversal image i' = N-2-i,
i' - i >= 2, let tau_i = (swap at i if independent) o (swap at i' if independent).  It
commutes with R and M, and tau_i, tau_i R, tau_i M are free on Y_i = {tau_i x != x}, but
tau_i RM has fixed points ("twisted self-dual" sequences).  Stabilisers are {1}, {1,RM},
{1, tau_i RM}, so
   #Y_i == #(Y_i cap Fix RM) + #(Y_i cap Fix tau_i RM)  (mod 8),
and x -> (swap at i only) is a bijection from the first set to the second, so
   #Y_i == 2 #{self-dual x : pair i of x independent}  (mod 8).
Rigid formula: take P = {n-1, n-3, ...} (N = 2n) or {n-2, n-4, ...} (N = 2n+1) and the
group E x V4, E = <tau_i : i in P> elementary abelian.  |G x| = 4 * 2^{i(x)} / eps(x),
i(x) = number of active tau_i, eps = 2 iff x is fixed by some e RM.  Hence
   a(N) == #Z + #T1 (mod 8),
Z = {x : no tau_i (i in P) active}, T1 = {x : exactly one tau_j active and x = RM x or
x = tau_j RM x}.  T1 is a half-size (self-dual type) count, but Z is not small:
#Z / a = 0.60, .083, .19, .018, .072, .0067, .023 (N = 4..16 even), .14, .375, .040,
.124, .012, .043 (N = 5..15 odd): it decays only slowly and irregularly, so #Z is of the
order of a itself up to a modest factor, far beyond enumeration at N = 40.
Iterating (new involutions on Z) keeps a residual set of the same nature.
File: enum.c (explicit enumeration N <= 16; out: enum_out.txt, all checks "ok").

4. RESIDUE TABLE (table.py)
------------------------------------------------------------------------------------------

 (full output: python3 table.py; a known to N = 38, c to N = 41)
 4..16 even: (a-c)/4 odd every time; 18..38 even: 0,1,0,1,0,0,0,1,0,0,0.
 odd N: 3:1 5:0 7:0 9:0 11:0 13:1 15:0 17:1 19:0 21:0 23:1 25:0 27:0 29:1 31:0 33:0
        35:1 37:0.
 No periodicity, no dependence on N mod 4 or 8 beyond c(4k+3) = 0.  Collisions showing
 that a mod 8 is not a function of (c mod 16, (c-d) mod 8): (c%16, (c-d)%8) = (2, 4)
 occurs for N = 10, 18, 30, 32, 38 with a mod 8 = 6, 2, 2, 6, 2; (6, 4) for N = 4, 22
 with a mod 8 = 2, 6.

5. PREDICTIONS FOR N > 38
------------------------------------------------------------------------------------------
 a(N) mod 8: none (no formula in terms of computable quantities was found; see section 0).
 a(N) mod 4 (from a == c, FINDINGS.txt): a(39) == 0, a(40) == 0, a(41) == 2.
 #midSwappable(N) mod 8 (section 2): known for every even N where c - d is computed,
 e.g. N = 28..38 above; it is a statement about a part of a(N) only.
