CoverAll: explicit certificates on a cell decomposition (the bulk), and what remains
====================================================================================

Lean: Folds/CoverAll.lean (imports Folds.Residual; no sorry, no native_decide), generated by
experiments/coverall/assemble.py from the parts in experiments/coverall/lean/ and the
generators genlean.py (cells), genbulk.py (leaves).  Notation as in experiments/residual/PROOFS.txt:
a pair (u, u'), 2 <= u <= u', u + 2u' <= N - 1, M = N + 2; in Lean the variables are N u v
with v = u'.

STATUS
  * PROVEN (Lean, `coverAll_of_thinCover`, `conjectureC_of_thinCover`):
        (forall N > 300, ThinCover N)  ==>  forall N > 300, CoverAll N  ==>  Conjecture C (all N),
    where ThinCover N says: every mixed-parity non-special pair of the triangle lying in
        Thin N u u' :=  u <= 3                                        (small)
                      \/ u' <= u + 9                                  (diagonal strip)
                      \/ 2u - 12 <= u' <= 2u + 15  /\  N <= 8u + 320  (the strip u' ~ 2u, Y >~ 1/8)
                      \/ N <= 4u + 80 /\ 4u <= N + 40 /\ N - 1 - u - 2u' <= 80   (cluster near (N/4, 3N/8))
    lies in Proven2 -- except the line u' = u + 1 with 5 <= u, 3u + 21 <= N, which is proven
    (`d1_line`, an explicit slice certificate, section 4); ThinCover is stated for
    ThinRest = Thin minus that line.  I.e. the whole 2-D bulk of the pair triangle is done, for all
    N >= 301, uniformly; what remains are thin sets (1-parameter families of lines with bounded
    offset, and a bounded box in offset coordinates around one point of the edge).
  * NOT proven: ThinCover N.  Numerically (thin.c) most thin points are covered by further edge
    certificates (families Z/X0/X1, orientations, directions (1,1), (2,1), (3,2), ...); the points
    covered by NO edge certificate (they need slices, RegionSL, or RegionS) are, for N = 3000/3001:
        diagonal: d = u' - u in {0, 1, 2, 3} (d = 0: all 252 pairs; d = 1: 259/401; d = 2: 110/574;
                  d = 3: 11/673 near the corner u ~ N/3; d = 4, 5: <= 5 pairs at N ~ 300)
        strip u' = 2u + e, e in [-9, 7], u >= N/8 - 5 (about 600 pairs at N = 3000)
        cluster: 5 - 8 pairs per N with |u - N/4| <= 2, N - 1 - u - 2u' <= 10
        small: u = 2, 3 (RegionS) and (5, 8), (5, 9)-type shapes.
    These are exactly the resonances of experiments/residual/PROOFS.txt section 3 (slope 1, slope 2,
    and the point where the edge certificates for slopes 1 and 2 both degenerate).

1. Edge certificates (Lean: famCons_nonneg, edge4_corner, parOK_edge4, edge1_corner, parOK_edge1)
--------------------------------------------------------------------------------------------------
Family (K, L, R, alpha, beta, smax, amin), witness polygon Pi = famCons (13 affine conditions in
(a, c), "every upper s-bound exceeds every lower s-bound by 1"), lattice direction w1 = (p, q),
w2 = (p2, q2), p q2 - p2 q = 1.  Pi is a strip between the edges
    f4: U2 - L1 = 1      (U2 = (Kc - beta)/R, L1 = (Ka - alpha + 1)/(L + 1))
    f1: U1 - L2 = 1      (U1 = (Ka - alpha)/L, L2 = (Kc - beta + 1)/(R + 1)),
cut below by "bottom" conditions and above by the two tops S - L1 >= 1, S - L2 >= 1.
f4-edge certificate (regime q L >= p (R + 1), Delta = q(L + 1) - pR > 0): parametrise the edge f4
by sigma = L1:  K a = sigma (L + 1) + alpha - 1,  K c = (sigma + 1) R + beta.  Take
    sigma1 = min(sigma8, sigma9),  sigma8 = s0 - 1 - Kp/(L + 1),  sigma9 = ((s0 - 1)(R + 1) - Kq - 1)/R - 1
(the w1-neighbour of the corner touches the a-top resp. the c-top; s0 <= smax a lower bound) and
sigma3 = sigma1 - K/Delta (the next lattice line q a - p c = const - 1).  The parallelogram
P = point(sigma1), sides w1 and w2 + delta w1 with delta = (c(sigma3) - c(sigma1) - q2)/q has
corners point(sigma1), point(sigma1) + w1, point(sigma3), point(sigma3) + w1.  At these corners the
13 conditions are affine in sigma and reduce (parOK_edge4) to the four KEY conditions at sigma3:
    chord: (sigma(L+1) - 1 + Kp)(R+1) - ((sigma+1)R + 1 + Kq)L - L(R+1) >= 0   (f1 at point + w1)
    bot:   sigma >= L + 1,   botR: sigma >= R + 1,   amin: sigma (L+1) + alpha - 1 >= amin K
plus the regime and s0 >= R + 1, 3.  All other 48 corner conditions follow by monotonicity in
sigma and in the shift e in {0, 1} (proved once, edge4_corner).  The f1-edge certificate
(regime pR >= q(L + 1)) is symmetric (parameter tau = L2, inner line tau1 = tau3 - K/Delta',
outer tau3 = min(tau8, tau9), Delta' = p(R + 1) - qL).
Since the keys are increasing in sigma3 = min(sigma8, sigma9) - K/Delta, each key holds iff it holds
for both choices; clearing denominators gives 8 polynomials of degree <= 4 in (N, u, u').
Validated numerically (valkeys.py: keys ==> all 52 corner conditions, 7226 random cases) and the
explicit corners agree with the exact ParOK test (certs.h / cover1.c reproduce the cells.c counts:
cell (1,1): 113876 = cells.c, cell (2,1): 35203 vs 35666 at N = 3001).

2. The cells (Lean: KeyA, KeyB4, KeyB1, parOK_of_keyA/B4/B1; generator gencell.py, genlean.py)
------------------------------------------------------------------------------------------------
Family Z, orientation (u', u): K = M, L = u', R = u, alpha = 0, beta = 1, amin = 2,
smax = M/2 (floor), s0 = (N + 1)/2.
    A  : w1 = (1,1), f4-edge, Delta = u' + 1 - u          (near the diagonal, u' <~ 1.5u .. 2.8u)
    B4 : w1 = (2,1), f4-edge, Delta = u' + 1 - 2u         (u' > 2u + 2)
    B1 : w1 = (2,1), f1-edge, Delta = 2u + 2 - u'         (u' < 2u - 1)
Key<c> N u u' = 2 <= u <= u', regime, 2u + 5 <= N, and the 8 key polynomials k<c><x><8|9> >= 0.
Asymptotic validity (keys.py / tmp/bounds.py, X = u'/N, Y = u/N, X in [Y, (1 - Y)/2]):
    A  : X - Y <~ (X + Y)/2 - 2XY (and d = u' - u >~ 6, the correction ~ (X+Y)/d)
    B1 : 2Y - X <~ (X + Y)/2 - 2XY, X < 2Y
    B4 : X > 2Y, up to b4hi(Y) (0.48 at Y = .01 ... the edge for Y >= .14)
    D  (old): X - Y >~ 4XY;   B (old): X >~ 1/4, Y <~ 1/8.

3. The leaves and the bulk theorem (Lean: leaf_*, regionD_of_polys, regionB_of_polys, bulk)
------------------------------------------------------------------------------------------
Outside Thin, with u >= 4, u' >= u + 10, the case split of `bulk`:
    2u' <= 3u                         -> A    (leaves L1a, L1b, L1c: the three half-spaces of
                                               "not cluster")
    3u < 2u', u' <= 2u - 13           -> B1   (L2a, L2c; the third half-space is empty)
    2u - 12 <= u' <= 2u + 15          -> D    (L4; not in the strip => N >= 8u + 321)
    2u + 16 <= u' <= 3u:  N <= 10u    -> B4   (L5)
                          N >  10u    -> D    (L6)
    u' > 3u:   100u' <= 36N           -> D    (L7a)
               100u' > 36N, 10u <= N  -> B    (L7b)
               100u' > 36N, 10u >  N  -> D    (L7c)
Each leaf is a polyhedron {N >= 301, u >= 4, u' >= u + 10, u + 2u' <= N - 1, u, u' >= 0, ...};
on it every needed polynomial (the 8 keys of the cell, or the conditions of RegionD with
u - u%2 >= u - 1, of RegionB with u/2 >= (u - 1)/2) is a nonnegative combination of products of
<= 4 of the leaf's linear forms (Handelman-type certificate).  leaves.py finds the support by a
float LP (handel.py: variables scaled by 1000 for conditioning, then the support is re-checked by
an exact rational solve, so the hints are exact); the Lean proof of each is `linarith` with those
products as hints (genbulk.py).  65 such certificates (plus 32 for d1_line); the whole file
elaborates in ~1 min (lake build, 4 threads).
The leaves were designed from the asymptotic picture (section 2); near the special points
(the triple point (1/8, 1/4) where the A-, D-, B-boundaries and the line u' = 2u meet, and the
point (1/4, 3/8) on the edge where the A- and B1-boundaries meet) the margins vanish, which is
why the strip and the cluster are thin sets.
Numerical cross-check (bulk.c: old regions or keys A/B4/B1 outside Thin, all parities):
0 failures for 301 <= N <= 3000 and N = 3001 + 997k <= 29920 (redundant given the proof).

4. What remains (ThinCover) and how it could be done
-----------------------------------------------------
thin.c lists, per thin class and offset, the points not covered by any edge certificate from a
library (Z, X0, X1; both orientations; w1 in {(1,1), (2,1), (3,1), (3,2), (4,3), (5,3)}; both
edges).  Everything else in Thin is covered by edge certificates whose key conditions are
polynomials in (N, u) on each offset line (or in (N, 4u - N, delta) on the cluster box), so the
same LP/linarith machinery applies (1 or 2 parameters instead of 3); not done.
The hard core (no edge certificate): d in {0, 1, 2, 3}, e in [-9, 7] (u' = 2u + e,
u >= N/8 - 5), the cluster points with |u - N/4| <= 2, delta <= 10, and small shapes.
Slices (slicefind.c, exact ParOK of Lean's sliceCons, constant j in [-3, 3]):
  * d = 1 (N odd, u' = u + 1): EVERY point (N = 3001) has the slice X0, orientation (u', u),
    a = c + 1 (p = 1, j = 1) with w1 = (1, 0) in the (s, c) plane, except at the corner
    u ~ N/3 where w1 = (3, 1).  In (s, c) the slice polygon is the intersection of the strips
    Nc in [(u - 2)s + 1, (u - 1)s] and N(c + 1) in [(u + 1)s, (u + 2)s - 1]; its horizontal chord at
    height c is  N(4c - u + 2)/(u^2 - 4) (c <= (u - 2)/3)  resp.  N(u - 1 - 2c)/(u^2 - 1)
    (c >= (u - 1)/3), maximal ~ N/(3u) at c ~ u/3, so the corners can be written explicitly
    (c0 ~ (u - 1)/3 - 1/2, s at the active lower bound); the margin N/(3u) - 1 vanishes only at
    u -> N/3 (a bounded number of offsets from the corner, each a 1-parameter family in N).
  * e-strip (u' = 2u + e): slices c = 2a + j (orientation (u, u'), family Z/X0/X1) or a = 2c + j
    (orientation (u', u)) with j in [-3, 3] depending on e, again with w1 = (1, 0) (occasionally
    (5,1)...(8,1)); e.g. e = 0: Z, (u, u'), c = 2a + 0;  e = -2: Z, (u, u'), c = 2a - 1;
    e = -6: Z, (u, u'), c = 2a - 3;  e = 3: Z, (u, u'), c = 2a + 1.
  So each hard line has a uniform slice certificate with constant (p, j) and explicit corners in
  (s, c); its 32 corner conditions are polynomial in (N, u) and the leaf machinery of section 3
  applies (2 variables).
  DONE for d = 1 (Lean `d1_line`, generator gend1.py): for 5 <= u, 3u + 21 <= N the corners
      c0 = (2u - 5)/6,  s0 = (N(2u + 1) + 6)/(6(u + 2)),  s1 = N(2u + 1)/(6(u - 1))
  (the two lines c0, c0 + 1 straddle the crossing c = (u - 1)/3 of the two lower bounds; s0, s1
  are the binding lower bounds there) satisfy all 32 conditions of sliceCons (smax replaced by
  N/2); each cleared condition has an LP certificate on {u >= 5, N >= 3u + 21, N >= 301} with at
  most 4 product hints.  Checked exactly (tmp/d1.py) to fail only at u = 4 and the last 6 values
  of u near N/3 for N <= 3001, in accordance with the hypothesis 3u + 21 <= N.
  Not done: the other hard lines, the ends of d = 1 (u <= 4, u > (N - 21)/3: bounded offsets from
  the corner, use w1 = (3, 1) or RegionS corner_d1), and the easy (edge-certificate) parts of Thin.
