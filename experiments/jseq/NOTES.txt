J(N), I(N), C_N(k) AND THE STRUCTURE OF WINDOW COPIES                  (experiments/jseq/)
=======================================================================================

Background: experiments/reccount/NOTES.txt (identities (A), (B)), experiments/neutral/PROOFS.txt,
Folds/Neutral.lean.  Notation: X ⊆ [N] is a (window) COPY if it is balanced around each of its
own elements; NEUTRAL if balanced around every panel.  g(S) = #valid orderings of S from
scratch.  C_N(k) = Σ_{X copy, |X|=k} g(Xᶜ).  J(k) = #valid k-sequences with no copy prefix of
size 2..k-1.  I(N) = #valid N-sequences with no neutral proper prefix.
   (A)  a(N) = 2a(⌊N/2⌋)a(⌈N/2⌉) + 2 Σ_{d|N odd, 3≤d<N} a(jN/d)a((j+1)N/d) + I(N)
   (B)  a(N) = J(N) + Σ_{k=2}^{N-1} J(k) C_N(k)

Summary
 * J(N) extended from N = 24 to N = 34 (sections 1-2), I(N) to N = 38 (it is explicit by (A)).
 * J(N)/a(N) is stable: ρ ≈ 0.18358 for N ≡ ±1 (mod 6), higher for even N (≈ 0.1853-0.1860)
   and for 3 | N (≈ 0.1868-0.1880), i.e. the same mod-6 arithmetic effect as a(N) (section 3).
 * Exact renewal form of (B): 1 = ρ_N + Σ_k ρ_k q_k(N), with ρ_k = J(k)/a(k) and
   q_k(N) = a(k)C_N(k)/a(N) = P(first k panels form a copy); q_k(N) converges fast
   (q_2 ≈ 0.634, q_3 ≈ 0.274, q_4 ≈ 0.141, q_5 ≈ 0.053, q_6 ≈ 0.031).
 * PROVEN (paper + Lean, Folds/Copies2.lean):
     - every copy with |X| > N/2 is neutral, so the copies of size > N/2 are exactly the
       odd panels (odd N), the E_dᶜ (odd d | N) and [N]; hence C_N(k) for k > N/2 is
       a(N-k) or 0 and the tail k > N/2 of (B) is explicit (section 4);
     - the number of copies of size 2 is ⌊N²/2⌋ - ⌊N²/3⌋ = ⌊(N²+2)/6⌋ (OEIS A156040(N-2));
     - copies of size N/2 (N even) = subsets of Z/(N/2) closed under i ↦ 2i and 2i+1 ↦ i;
       in particular only the two parity classes when N ≡ 2 (mod 4) (section 5).
 * Copies of size 3: (fitted, exact for N ≤ 200) N³/108 + period-6 linear + period-12
   constant term.  Size k ≥ 4: degree k, no quasi-polynomial of small period (section 6).
 * No exact recursion for a(N) through smaller a, J: C_N(k) for k ≤ N/2 is a sum of
   completion counts g(Xᶜ) with large prime factors; fixed linear combinations of products of
   smaller a's and J's miss C_N(2..4) by 2-19% on held-out N (section 7).
 * No OEIS hits for J, I, the total copy counts, the size-3 counts, or the half-size counts.

1. METHOD
---------
Identity (B) gives J(N) = a(N) - Σ_{k=2}^{N-1} J(k) C_N(k), and a(N) is known to N = 38.  So J(N)
only needs C_N(k) = Σ_{copies X, |X|=k} g(Xᶜ) for all k.  Copies are rare (6262 of the 2^32
subsets at N = 32), so jdp.c runs the plain forward DP for g over ALL layers (not just up to
N/2), keeping two colex-ranked layers, and reads g at the ranks of the copy complements as
each layer is finished.  Only ONE array is needed (no J-type kill state), so memory is
2·C(N, N/2) words:
   N = 31: u64, 4.8 GB, 45 s per modulus;   N = 32: u32, 4.8 GB, ~1.7 min per modulus;
   N = 33: u16, 4.7 GB, ~3.2 min;           N = 34: u8, 4.7 GB.
Every run also returns g([N]) = a(N) mod p, which matched the known a(N) in every run.  The
copy enumeration (copies.c) is a left-to-right DFS on the prefix form
   left half  (2m-1 ≤ N):  P(2m-1) = P(m-1) + P(m),
   right half (2m-1 > N):  P(m-1) - P(2m-1-N) = |X| - P(m),
and is instant for N ≤ 64 (it reproduces decomp.c's copy counts for N ≤ 24).
J(1..24) from (B) reproduce the values of experiments/reccount exactly.

Alternative (not implemented, for larger N): a meet-in-the-middle form follows from section 4:
   J(N) = Σ_{|S|=⌊N/2⌋, S not a copy} gJ(S)·g(Sᶜ) - Σ_{X∈NFam, |X|>N/2} J(|X|)·a(N-|X|),
with gJ the forward DP that kills copy prefixes; it needs gJ and g on layers ≤ N/2 only (half
the time, but two arrays, so no memory gain over the full-layer g run).

4. LARGE COPIES ARE NEUTRAL   (proven; Lean: Folds/Copies2.lean)
-------------------------------------------------------------------
Notation as in experiments/neutral/PROOFS.txt: x_k the N-periodic indicator, P(t) = x_1+...+x_t
(P(t+N) = P(t) + s, s = |X|), h(t) = N·P(t) - s·t (N-periodic, h(t+1) - h(t) = N x_{t+1} - s).
By Lemma 1.1 there (balF_iff_P), X is balanced around m ∈ [N] iff D(m-1): P(2m-1) = P(m-1)+P(m),
and D(k) ⇔ D(k+N).  So
   X is a copy  ⇔  D(k) for every k with x_{k+1} = 1.                          [copy_dbl]

Lemma 4.1 (discrepancy bound for copies).  For a copy X:  -(N-s) ≤ h(t) ≤ N - s for all t.
                                                                              [hd_bounds_copy]
Proof.  s = 0 is trivial.  Let M = max h = h(t0).  If x_{t0} = 0 (read t0 + N for t0 = 0) then
h(t0 - 1) = M + s > M; so x_{t0} = 1 and D(t0 - 1) holds: h(2t0 - 1) = h(t0 - 1) + h(t0) ≤ M
gives h(t0 - 1) ≤ 0, hence M = h(t0 - 1) + N - s ≤ N - s.  Let L = min h = h(t1).  If
x_{t1+1} = 0 then h(t1 + 1) = L - s < L; so x_{t1+1} = 1 and D(t1) holds:
h(2t1 + 1) = h(t1) + h(t1 + 1) ≥ L gives h(t1 + 1) ≥ 0, hence L = h(t1 + 1) - (N - s) ≥ -(N-s). □
(The neutral bound |h| ≤ min(s, N-s) needs D at the other neighbours too; a copy only has the
half that uses its own elements.)

Lemma 4.2 (size).  If |h| ≤ μ everywhere then g·⌊d/2⌋ ≤ μ, where g = gcd(s, N), d = N/g.
                                                                             [size_bound_gen]
Proof: as Lemma 2.3 of PROOFS.txt (h(t) ≡ -s t (mod N) takes the value g⌊d/2⌋ mod N).       □

Theorem 4.3.  A copy X ⊆ [N] with 2|X| > N is neutral.  Hence the copies of size k > N/2 are:
[N] (k = N), the odd panels (N odd, k = (N+1)/2), and E_dᶜ (k = (d+1)N/(2d), d | N odd, 3 ≤ d < N);
each size occurs at most once.                     [copy_large_neutral, copy_large_mem]
Proof.  Let s = |X| < N, s = g a, N = g d.  Lemmas 4.1-4.2 with μ = N - s: ⌊d/2⌋ ≤ d - a.  With
2a > d this forces d odd and 2a = d + 1, d ≥ 3 (a < d), i.e. 2sd = (d+1)N.  [copy_size]
Uniqueness: two copies X, X' of size s > N/2 have |h - h'| ≤ 2(N - s) < N, and h - h' =
N(P - P'), so P = P' and X = X'.  [copy_unique]  The odd panels (d = N) and E_dᶜ (d < N) are
neutral copies of exactly these sizes, so X is one of them.                               □

Corollary 4.4.  For N/2 < k < N:  C_N(k) = a(N - k) if k = (N+1)/2 (N odd) or k = (j+1)N/d for an
odd d | N, 3 ≤ d < N (j = (d-1)/2); otherwise C_N(k) = 0.                       [CN_large]
So identity (B) becomes  [identity_B_split]
   a(N) = J(N) + Σ_{k=2}^{⌊N/2⌋} J(k) C_N(k) + Σ_{X ∈ NFam(N), |X| > N/2} J(|X|) a(N - |X|),
and only the terms k ≤ N/2 involve completion counts.  Checked against the DP for all N ≤ 34.
(The tail is tiny: Σ_{k>N/2} f_k ≈ 1e-6 of a(N) at N = 31.)


5. COPIES OF SIZE 2 AND OF SIZE N/2   (proven; Lean: Folds/Copies2.lean)
------------------------------------------------------------------------
5.1  {x < y} is a copy iff 2x ≤ y (balance at x) and x + N + 1 ≤ 2y (balance at y).
     [isCopy_pair]  These are exactly "y then x is a valid 2-prefix" and "x then y is valid".
     Hence #copies of size 2 = #valid 2-prefixes - #reachable 2-sets = ⌊N²/2⌋ - ⌊N²/3⌋
     = ⌊(N²+2)/6⌋ (Prefix.lean: card_prefixTwo, card_reachTwo).            [card_copies_two]
     OEIS: A156040(N-2) = A007590(N) - A000212(N) (g.f. x²(1+x²)/((1-x)(1-x²)(1-x³))).

5.2  Half-size copies.  Let N = 2n and |X| = n.  Lemma 4.1 gives |h| ≤ n, i.e. |2P(t) - t| ≤ 1,
     so P(2u) = u: X has exactly one panel in each pair {2i+1, 2i+2}.        [copy_half_P]
     Write B(i) = x_{2i+1} (i ∈ Z/n).  With P(2i) = i, P(2i+1) = i + B(i):
       D(2i)   (needed when B(i) = 1):  P(4i+1) = 2i + B(2i)  =  2i + 1   ⇔  B(2i) = 1;
       D(2i+1) (needed when B(i) = 0):  P(4i+3) = 2i+1 + B(2i+1) = 2i+1  ⇔  B(2i+1) = 0.
     Theorem 5.2.  The copies of size N/2 are exactly X_U = {2i+1 : i ∈ U} ∪ {2i+2 : i ∉ U} for
     the U ⊆ Z/n closed under i ↦ 2i and under 2i+1 ↦ i (equivalently: m ∈ X ⇒ 2m - [m odd] ∈ X,
     panels mod N).                                                          [copy_half_iff]
     Corollary [copy_half_odd].  If n is odd (N ≡ 2 mod 4) the only copies of size N/2 are the two
     parity classes.  Proof: put j = (i-1)(n+1)/2, so 2j ≡ i-1 and 2j+1 ≡ i (mod n).  The edges
     i = 2j+1 → j → 2j = i-1 show that i ∈ U ⇒ i-1 ∈ U, so the closure digraph is strongly
     connected and only U = ∅ (evens), U = Z/n (odds) are closed.                         □
     Counts (N = 2n; halfcopies.py, = copies.c for N ≤ 80):
       N   4 8 12 16 20 24 28 32 36  40  44  48  52   56  60   64  68    72  76    80
       #   3 5  8 12  8 35 20 95 24 249  8 744  8 1761 112 7091 20 10847  8 57095
     and 2 for every N ≡ 2 (mod 4).  For N = 2^L: 3, 5, 12, 95, 7091 (L = 2..6), growing fast:
     the closure digraph on Z/2^(L-1) has only singleton components.  No OEIS match.

5.3  Just below N/2 (observed, not proven).  For odd N the copies of size (N+1)/2 - j number
       1, 4, 12, 24, 64, 132, 264, 584, 1800, 2736, 6408, 19200, 32400, 70032, ...
     for every prime-like N large enough (stable once N ≳ 6j; checked N = 59..83; numbers with
     small odd divisors differ).  For N ≡ 2 (mod 4) the sizes N/2 + 1 - j give
       1, 2, 9, 8, 72, 32, 396, 160, 2916, 512, 15264, 2176, ...
     The four copies of size (N-1)/2 (odd N ≥ 9; observed for N ≤ 64) are the evens with
     2 → 1 and/or N-1 → N; their completion ratios g(Xᶜ)/a((N+1)/2) are 1 (evens, neutral),
     1/2, 1/2 EXACTLY (one swap; checked N ≤ 33) and ≈ 0.20-0.36 (both swaps), so
     C_N((N-1)/2)/a((N+1)/2) ≈ 2.25.
     Proof of the 1/2 (paper).  Let n = (N+1)/2 and Y = Xᶜ = (odds \ {1}) ∪ {2}.  Relabel
     1 ↦ 2.  For an odd panel m ≥ 3 an arm of m contains 2 iff it contains 1 (left half: the
     left arm is [1, m-1]; right half: the left arm starts at the odd number 2m-N, so it
     contains 2 iff 2m - N ≤ 1 iff it contains 1); the right arms of m ≥ 3 contain neither.
     Panel 1 is always valid, panel 2 is valid iff 3 is not yet placed (arms {1}, {3}, 1 ∉ Y).
     So the valid orderings of Y are the valid orderings of the odd panels (a window copy:
     valid n-sequences) in which 1 comes before 3, i.e. the valid n-sequences with 1 before 2;
     by reversal invariance these are exactly half.  The same argument at both ends gives
        C_N((N-1)/2) = 2a(n) + #{valid n-sequences with 1 before 2 and n before n-1}
     (check_near.py: brute force, N = 9..17)
     (given the observed list of the four copies).


6. COUNTS OF COPIES OF FIXED SIZE k (as functions of N)
-------------------------------------------------------
 * k = 2: ⌊(N²+2)/6⌋ (proven, 5.1).
 * k = 3: exact for all N ≤ 200 (qpfit.py; period 12):
     #copies_3(N) = N³/108 + c1(N mod 6)·N + c0(N mod 12),
     c1 = (0, 1/18, -1/9, 1/6, -1/9, 1/18),
     c0 = (0, -7/108, 4/27, 1/4, -4/27, -47/108, 0, 47/108, 4/27, -1/4, -4/27, 7/108);
     e.g. #copies_3(6m) = 2m³.  (A quasi-polynomial is expected: the copy conditions are linear
     inequalities in (x, y, z, N) for each order type, as for T(N, k).)
 * k = 4, 5, 6: growth N^k (fitted exponents 3.99, 4.98, 5.96), leading coefficients
   ≈ 8.14e-4 (≈ 1/1228), 1.78e-5 (≈ 1/56000), 1.26e-6 (≈ 1/795000) (least squares; the
   volume of the continuum copy region; k = 2, 3: 1/6, 1/108); no quasi-polynomial of
   period < 200 fits the data (N ≤ 150 / 120 / 100) -- too few points per residue for
   periods like those of T(N,4) (168), so this is not evidence against quasi-polynomiality.
 * Copies are not "Beatty-like" in number: the totals grow fast (3.8e6 at N = 64) and are
   dominated by sizes ~N/4..N/2.  The Beatty-type structure appears only at the top: above
   N/2 there are only the neutral sets E_dᶜ (sizes (d+1)N/(2d)), at N/2 the 2-adic closed
   sets, just below N/2 universal near-class counts.
 * WHICH SIZES OCCUR (proven, copies_nonempty_iff): for 1 ≤ k ≤ N there is a copy of size k
   iff 2k ≤ N + 1 (the Beatty copy {⌊rN/k⌋}, Copies.winEmb_beatty), k = N, or k = (d+1)N/(2d)
   for an odd divisor 3 ≤ d < N of N, i.e. (2k - N) | N with N/(2k - N) odd.  So the number of
   sizes is ⌈N/2⌉ + #{odd d | N : 3 ≤ d < N} + 1 (N ≥ 2), and every size k > N/2 that occurs
   occurs exactly once.  (Checked against copies.c for N ≤ 64.)


7. IS THERE AN EXACT RECURSION THROUGH a AND J?
----------------------------------------------
 * By Corollary 4.4 the part k > N/2 of (B) is a polynomial in a and J.  The part k ≤ N/2 is
   not: C_N(k) = Σ_{copies} g(Xᶜ) and the individual completion counts are not products of
   a-values (e.g. N = 20, copies of size 8: g(Xᶜ) = 85199 (prime), 93182 = 2·46591,
   154029 = 3·51343, ...; only the neutral E_5 gives a(12) = 383476).  For size-2 copies,
   g(Xᶜ)/a(N-2) ranges continuously over 0 ({1, N} for even N is dead) .. 0.38.
 * Over all 38688 copies X with 2 ≤ |X| ≤ N-1, N ≤ 33: g(Xᶜ) ≤ a(N - |X|) always, with
   equality exactly for the 109 neutral X (so "g(Xᶜ) = a(N-k) iff X neutral" of reccount §2
   holds to N = 33); the largest non-neutral ratio is 0.69-0.85 (0.8427 at N = 32).
 * relfit.py: fitting C_N(k) (k = 2, 3, 4) exactly on N = 12..24 by a fixed combination of 13
   terms (a(N-k), a(N-k-1), J(N-k), J(N-k-1), J(N-k-2), a(i)a(N-k-i) for i = 2..4, N·a(N-k),
   N²·a(N-k), N·a(N-k-1), N·J(N-k), N·J(N-k-1)) misses N = 25..32 by 2-19%.  No relation.
 * Exactly as in reccount section 5, the copy-indecomposable remainder J(N) is a stable 18% of
   a(N), and the coefficients are completion counts of co-copies, a genuinely new quantity.
   Conclusion: no exact recursion for a(N) in terms of smaller a, J and copy counts alone.
